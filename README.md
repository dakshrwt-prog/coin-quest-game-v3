# Coin Quest — Feel & Accessibility Update (v3)

A small browser game where you collect 15 coins in 60 seconds while avoiding hazards.

## Run it
Open `index.html` in a modern browser, or publish the repository with GitHub Pages.

## Controls
- Move: Arrow keys or WASD
- Pause/resume: P or Escape
- Restart after a round: R, or use the on-screen button
- Touch: on-screen directional buttons on narrow screens

## Feedback and accessibility
- Optional short Web Audio sound cues; toggle **Mute sound**.
- **Reduced motion** disables particle bursts and coin pulsing.
- Settings and high score are saved locally in the current browser when storage is available.
- Visible keyboard focus, labelled settings, and live feedback announcements are included.

## Supporting evidence
- `PLAYTEST_NOTES.md`: same questions and task list for at least three real playtesters. Fill in real observations; do not fabricate responses.
- `BEFORE_AFTER_EVIDENCE.md`: instructions for capturing actual v2 and v3 screenshots.
- `STATE_DIAGRAM.md` and `EDGE_CASE_TESTS.md`: state transitions and previous edge-case checklist.

## Publish one proof link
1. Upload all project files to the same public GitHub repository.
2. Add the screenshots in an `evidence/` folder after capturing them and complete `PLAYTEST_NOTES.md`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Share the published GitHub Pages URL. Keep the playtest notes, screenshots, and checklist in this same repository so one repository/site link contains the supporting material.
